### API 成本一眼看懂

| 路线 | STT / ASR | TTS | 外部按量 API 费主要来自 |
| --- | --- | --- | --- |
| **本地优先（知己采用的核心思路）** | 本地部署 | 本地部署 | **文本 LLM** |
| 混合方案 | 本地 | ElevenLabs 等云 TTS | LLM + TTS |
| 完全云 API | ElevenLabs / Soniox 等 | ElevenLabs / Cartesia 等 | LLM + STT + TTS |

**关键区别：** 本地 STT/TTS 的云端按次调用费可以为 $0，但设备、算力、电力、网络与维护绝非免费。教程中的金额只是一组特定用量与公开标价的历史示例，不是产品报价，订阅与价格可能变动。

### 最值得自己掌握的四层

1. **流式管道**：采音、识别、生成、合成、播放彼此并行。
2. **话轮判定**：短暂停顿不等于用户说完。
3. **打断仲裁**：疑似人声不等于确认打断，考虑回声和 ASR 证据。
4. **播放权管理**：每次生成有 generation ID，迟到的旧音频必须丢弃。
